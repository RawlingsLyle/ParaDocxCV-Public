# ParaDocx Desktop Releases

This repository hosts packaged ParaDocx desktop releases, update assets, and concise user-facing release notes. Application source and development history are maintained privately.

Download signed macOS Apple Silicon installers from [Releases](https://github.com/RawlingsLyle/ParaDocxCV-Public/releases) when available. No app release has been published yet.

To install, open the DMG and drag ParaDocx into Applications. Updates download quietly and ask before restarting. Your CV remains stored locally on your Mac.
