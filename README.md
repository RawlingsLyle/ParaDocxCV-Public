# ParaDocx Desktop Releases — Version 1.01

This repository hosts packaged ParaDocx desktop releases, update assets, and concise user-facing release notes. Application source and development history are maintained privately.

The [unsigned macOS Apple Silicon testing preview](https://github.com/RawlingsLyle/ParaDocxCV-Public/releases/tag/preview-v1.0.1-ee6ebe5-20261112064133) is now available and displays **Version 1.01** at the top of the app. Under Assets, choose the **UNSIGNED-PREVIEW ZIP** to download the actual app, rather than GitHub's source-code archives.

Unsigned previews require manual installation and manual updates, and macOS may block opening them. Read the release's installation notes before proceeding. Future signed production releases will support automatic updates. Your CV remains stored locally on your Mac.

Downloads contain no saved CV or starter profile. An existing local CV is preserved when replacing the app; ParaDocx has no built-in CV synchronization.
