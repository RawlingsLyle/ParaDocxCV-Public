# ParaDocx Desktop Releases

This repository hosts packaged ParaDocx desktop releases, update assets, and concise user-facing release notes. Application source and development history are maintained privately.

Release downloads will appear under [Releases](https://github.com/RawlingsLyle/ParaDocxCV-Public/releases). No app release has been published yet.

Unsigned macOS Apple Silicon previews are testing builds: manual installation and manual updates only, and macOS may block opening them. Read each build’s installation notes. Future signed production releases will support automatic updates. Your CV remains stored locally on your Mac.
